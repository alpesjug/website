==  Programme de la soirée

Kubernetes s'est imposé comme l'orchestrateur de conteneurs de référence, permettant de déployer des applications sans (trop) se soucier de l'infrastructure sous-jacente. S'il est extrêmement robuste, Kubernetes reste un système imposant avec un grand nombre de composants et beaucoup de concepts à appréhender. Un opérateur Kubernetes est un composant qui permet de réduire, voire masquer, la complexité de Kubernetes pour les ingénieurs. Il simplifie la configuration requise pour déployer une application, en amenant des abstractions de plus haut niveau qui mettent en œuvre les bonnes pratiques connues. Il permet également d'automatiser certaines opérations de maintenance, réduisant ainsi le risque d'erreurs en production.

Durant cette présentation, après être rentrés dans les détails de l'architecture de Kubernetes, nous découvrirons comment écrire nos propres des opérateurs Kubernetes avec l'excellent Java Operator SDK. Nous nous appuierons sur deux exemples concrets d'opérateurs, code et démonstration à l'appui.
