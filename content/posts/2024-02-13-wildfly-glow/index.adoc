==  Programme de la soirée

Cette présentation est une introduction a WildFly Glow, une nouvelle approche pour le provisioning de WildFly.
Le provisioning de WildFly en général sera tout d'abord présenté, ses limites détaillées puis nous verrons comment WildFly Glow simplifie drastiquement l'expérience utilisateur.
Pendant la présentation le tooling de WildFly Glow sera démontré.

== Le conférencier: Jean-François Denise

Jean-François est un "Principal software engineer" chez Red Hat. Il est impliqué dans le tooling ainsi que le WildFly provisioning (WildFly CLI, WildFly Bootable JAR, Openshift images, WildFly Glow).
